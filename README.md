## About

I build software end to end — from the database schema through to deployment — with a
particular interest in what happens when a system is put under pressure and begins to fail.

My work centres on backend engineering in Java and Spring Boot, extending into full-stack
web and mobile development. Alongside that, I work in data science and in security, where
I find both sides equally worthwhile: building the defences, and understanding how they break.
